# common_words.txt — the Lexicon rarity gate's "everybody knows this one" list.
#
# A hand-curated sweep of frequent English word STEMS, one per line, lowercase,
# ASCII only, sorted. Lines starting with '#' and blank lines are ignored.
#
# WHAT THIS IS FOR. `lexicon_live.rare_word()` offers a definition only for a
# long-ish, all-lowercase, alphabetic token that is NOT in here after its
# endings are stripped. Zipf does the work: the words a wearer would be
# surprised to be told the meaning of are overwhelmingly the frequent ones, so
# a list of the frequent ones is a rarity test that needs no model, no corpus
# at runtime and no network.
#
# WHY STEMS RATHER THAN FORMS. `lexicon_live.stems()` strips the inflectional
# and productive derivational endings (-s/-ed/-ing/-ly/-er/-est/-ness/-ment/
# -ful/-less/-able/-ation/-ance/-ence/-ical/-ion/-ous/-ive/-ist/-al/-ship)
# before the membership test, so one entry covers a whole family ("question"
# covers questions/questioned/questioning; "install" covers installation).
# Entries may be any length: an eight-letter candidate often reduces to a short
# stem ("meetings" -> "meet").
#
# WHAT A MISS COSTS. Both failure directions are soft. A common word missing
# from this list draws one quiet definition card, once per session (the dedupe
# set), for a word the wearer already knew. A rare word wrongly present draws
# nothing. Neither is a defect worth a model — so extend this list freely when
# a false positive is spotted, and do not agonise over completeness.
#
# WHAT THIS IS NOT. It is not a stopword list (those live per-purpose in
# orchestrator/tell.py, pipelines/ingest.py, orchestrator/commitment_drift.py)
# and it is not a spell-checker dictionary — a spelling dictionary contains the
# RARE words too, which is exactly backwards for this job.
